# Heli — Art, Stories & Beyond

A personal art portfolio and storytelling website. Visitors can explore my paintings, read the stories behind them, and (later) buy originals or request commissions.

I'm a Computer Science student building this from scratch to learn full-stack development.

## Tech stack

| Layer | Technology |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Backend (planned) | Java + Spring Boot |
| Database (planned) | SQL |
| Hosting | GitHub Pages (free) for now; backend hosting decided later |
| Payments (planned) | Stripe |

## Roadmap

- [ ] **Phase 1 — Frontend foundation:** homepage, navigation, hero, gallery, stories, shop
- [ ] **Phase 2 — Design:** visual identity, responsive layouts, animations
- [ ] **Phase 3 — Backend:** Spring Boot app + database
- [ ] **Phase 4 — Admin dashboard:** secure login, manage artwork and stories
- [ ] **Phase 5 — Advanced features:** comments, likes, saves, commissions, purchasing
- [ ] **Phase 6 — Deployment:** live on the internet (free hosting first, paid only if needed)

## Progress log

- **Day 1:** Set up the project and first HTML page.
- **Day 2:** Organized the folder structure, linked CSS and JS, built the homepage skeleton (sticky nav, hero, placeholder sections, footer) and a color palette based on the logo.

## Run it locally

No build step yet: just open `index.html` in a browser.
